# Real / client IFC samples

Drop any real-world `.ifc` file here (e.g. a client-supplied model) to open it in the app's
**Open IFC File** mode (`src/app.py`) — view it in 3D, browse its elements, and ask the chat
assistant questions about it.

`*.ifc` files in this folder are **git-ignored** (large, and may be confidential) — copy your own
in locally. The app also lists anything generated by the IFC Design Studio
(`outputs/ifc_design/*.ifc`) in the same file picker.

First load of a large file triangulates its geometry (can take a minute or two for a few thousand
elements); the result is cached to `outputs/ifc_cache/` keyed by file name + size + modified time,
so reopening the same file is instant until it changes.
